Tendril

Version 1.0.46 is out!

This update brings native desktop notifications, a taskbar badge showing active jobs, and a completely redesigned onboarding experience that gets you productive in three steps instead of ten.

We've added full CLI CRUD for projects and verifications, and support for multiple coding agents: Claude Code, OpenCode, Copilot, Codex and Gemini.

Model Providers

With the addition of OpenCode support, we can now integrate with virtually any model provider. Whether you prioritize data sovereignty, lower costs, or provider flexibility, we've got you covered.

Guides: Berget.ai, Everoc, Z.ai, Scaleway, Opper.ai, OpenRouter, Cloudflare, NVIDIA, Vercel

Update Tendril

Type this in your terminal to update Tendril to the latest version:

$ dotnet tool update -g Ivy.Tendril

If you experience issues after updating try tendril reset to get a clean installation.
