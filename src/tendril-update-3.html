Tendril

Version 1.1.27 is out!

The Ivy team has worked during the summer with a selected group of design partners and has made significant changes based on their input.

• Cloudflare tunnels — Work with Tendril on a phone or tablet.
• Chat with agent — Tendril aware agents directly in Tendril.
• Annotate drafts — Add comments on selected text.
• Create plans — Using voice, file and image from clipboard.
• Code reviews — Make comments on lines for the agent to improve.
• Git synchronization — Ensures your worktrees are synced with the latest changes in origin.
• Recommendations — Trigger multiple recommendations.

… plus lots of bugfixes and quality of life additions.
