# AddProject

Analyzes and initializes a newly added project and its repositories in Tendril.

## Parameters
- **ProjectName**: Name of the project (e.g. `{{ProjectName}}`)
- **ReposJson**: Repositories associated with the project

## Task
1. Inspect project `{{ProjectName}}` configuration and repository structures.
2. Verify build/test dependencies and review actions for `{{ProjectName}}`.
